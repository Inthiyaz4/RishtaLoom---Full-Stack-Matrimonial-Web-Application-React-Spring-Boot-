# 💑 RishtaLoom - Matrimonial Web Application

**RishtaLoom** is a modern and user-friendly matrimonial (shaadi/rishta) web portal that allows users to register, explore matches, and manage their profiles. Built with **React.js** for the frontend and **Spring Boot** for the backend.

---

## 🔍 Features

- 📝 User Registration & Login
- 👤 My Profile (View / Update / Delete)
- 👫 Browse Other Profiles (Customers)
- 🎯 Filter by caste, age, job, and location
- 📤 Upload Profile Pictures
- 📧 Contact Form to Admin (via EmailJS)
- 🔐 Local storage session management
- 🌐 Responsive design (mobile friendly)

---

## 🚀 Tech Stack

| Layer        | Technology               |
|--------------|--------------------------|
| Frontend     | React.js, React Router   |
| Styling      | CSS, Bootstrap           |
| Backend      | Spring Boot (Java)       |
| Database     | MySQL / H2 (optional)    |
| Email Service| EmailJS (for contact)    |
| HTTP Client  | Axios                    |
